# Suchalgorithmen für einen Pacman-Agenten

Python-Praktikumsprojekt zur Wegsuche in einer vorgegebenen Pacman-Umgebung. Der Agent sucht den Weg zum nächsten Punkt und führt die gefundenen Schritte aus.

## Enthaltene Verfahren

- Breitensuche und Tiefensuche.
- Uniform-Cost Search.
- Greedy-Suche und A* mit Manhattan-Distanz.

## Dateien

- `PacmanAgent.py`: Verbindung zwischen Spielumgebung und Suche.
- `P3/Suche.py`: Auswahl und Durchführung des Suchverfahrens.
- `P3/Knoten.py`: Zustandsdarstellung und Erzeugung von Nachfolgezuständen.
- `P2/Knoten.py`: früherer Praktikumsstand.

## Ausführung

Dieses Repository enthält die studentischen Komponenten, nicht das vollständige Spiel. Es benötigt das externe Praktikumsgerüst mit `game_core` und dessen Verzeichnisstruktur `Backend.Student_Files`. Ein eigenständiger Start nach dem Klonen ist daher nicht möglich.

Der Code dokumentiert die Implementierung der Suchverfahren im Studium. Aussagen über Vollständigkeit oder optimale Wege müssen für das jeweilige Verfahren und die konkrete Zustandsdarstellung gesondert geprüft werden.
